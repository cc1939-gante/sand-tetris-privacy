一、适用范围与同意

本政策适用于《细沙方块》的 Android 安装版、TapPlay 版与 TapTap 小游戏版（Android 包名：com.pixelsand.sandtetris）。游戏提供单机玩法，无内购、社交或用户内容发布功能。Android 安装版及 TapPlay 版包含开屏、横幅、插屏和激励广告。小游戏版提供玩家主动选择的激励视频，用于获取复活、道具或分数奖励。

首次启动及政策版本变更时，本游戏展示政策摘要和完整文本。您可以离线阅读，阅读和返回均不表示同意。点击“同意”后，本游戏才启用广告服务；点击“不同意”后可以继续离线游玩，广告及其奖励入口关闭。您可以从主菜单或暂停页阅读本政策，也可以在全文页重新选择启用广告。

二、信息收集和使用

本地信息：游戏仅在您的设备上保存最高分、音效和震动开关、操作方式、滑动灵敏度以及政策版本同意记录，用于保留成绩与偏好。游戏业务代码不上传这些本地记录，不设置独立用户账号体系，无需登录账号或提交姓名、身份证号码即可游玩。

Android 安装版及 TapPlay 版广告：经您同意后，TapADN 为展示广告、效果统计、归因、反作弊及运行诊断，可能处理设备型号、系统版本、屏幕参数、语言、时区、CPU 和存储信息、广告标识 OAID、IP 地址、网络状态、应用包名和版本、广告曝光、点击、转化、崩溃及性能数据。游戏关闭原生 SDK 的个性化广告，并限制位置、电话状态、Android ID、应用列表、Wi-Fi 标识、外部存储及传感器访问。游戏不向 SDK 传入设备标识作为奖励用户 ID。

TapTap 小游戏广告：您同意本政策后，游戏通过 TapTap 小游戏接口创建激励视频广告，您点击奖励按钮时请求展示。TapTap 客户端会依据其平台政策处理广告展示、互动及设备和网络等信息。游戏仅根据平台返回的是否完整观看结果发放本地奖励。

您的来信可能包含问题描述和回复地址，用于处理您提出的请求。

三、系统权限

Android 的网络权限（INTERNET、ACCESS_NETWORK_STATE）用于您同意后的广告请求及网络检测；震动权限（VIBRATE）用于您开启震动后的操作反馈。这些系统权限不会产生运行时授权弹窗。广告 SDK 可能通过部分厂商提供的设备标识服务获取 OAID。

游戏不会为广告申请位置、电话状态、蓝牙、通知、读取已安装应用列表或安装未知应用的权限。小游戏由 TapTap 客户端运行，客户端的系统权限可在系统设置中管理。

四、第三方 SDK 与共享清单

Unity 引擎；提供者：Unity Technologies。用途：运行画面、音频、触屏输入和本机存储。涉及运行所需的设备及环境信息。本游戏未接入 Unity Ads 或 Unity Analytics 服务。隐私政策：https://unity.cn/legal/china-privacy-policy

TapADN / Dirichlet Ad SDK；提供者：上海艾得蒽数字科技有限公司及其关联方；Android SDK 版本：5.3.1.8。用途：广告展示、归因、统计与反作弊。适用信息范围、方式及场景见第二、三节。隐私政策：https://ssp.dirichlet.cn/docs/agreement/

TapTap 小游戏平台；提供者：易玩（上海）网络科技有限公司。用途：运行小游戏和提供激励视频接口。平台服务及用户信息处理规则请见 https://www.taptap.cn/doc/privacy-policy。

第三方仅应按相应功能所需范围处理信息；具体权利管理与保存规则可查阅其政策。本游戏不出售您的个人信息。除提供上述服务、获得您的相应同意或依法履行义务外，不对外提供个人信息。如发生合并等需要转移个人信息的情形，将向您告知接收方并要求其继续履行保护义务。

五、存储与安全

本地成绩、设置和同意记录保存在您的设备上，可通过系统清除游戏数据删除。广告数据由 TapADN 依据其政策在中国境内处理和保存；游戏不自建存放广告用户信息的业务服务器。第三方的数据保留期限及删除方式请查阅其政策或通过我们协助咨询。

我们仅在实现相应目的所需期限或法律要求的期限内保留信息，采用必要的访问限制等保护措施。如发生个人信息安全事件，将按适用规定采取补救措施并履行告知、报告义务。

六、您的权利

您可随时阅读政策。Android 安装版可在系统设置中清除本游戏数据，小游戏可在 TapTap 客户端清除小游戏本地数据。清除会同时删除本地成绩、设置和隐私选择。下次启动会重新询问，您可选择不同意并离线游玩。撤回不影响撤回前基于同意已经开展的处理。

本游戏无需注册账号；如您希望查阅、复制、更正、删除广告服务涉及的信息，或管理广告推荐、投诉及提出其他个人信息请求，请联系下文邮箱，我们将核实并按需协调 SDK 提供方处理。我们将在十五个工作日内答复。

七、未成年人保护

未成年人请在监护人指导下阅读本政策。涉及不满十四周岁儿童的个人信息处理，应取得监护人的相应同意。监护人如发现儿童信息被不当处理，可以通过下文邮箱联系我们提出删除或其他请求，我们将核实并及时处理。游戏没有内购，不提供付费道具购买。

八、政策更新

涉及信息处理范围等实质变化时，我们会更新政策版本，并在您下次启动游戏时重新征求同意。当前版本的政策可通过游戏内入口离线查阅。
